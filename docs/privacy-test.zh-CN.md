# 共享屏幕隐私 —— 真机测试步骤（v1.0.1）

准备：两台设备（A=老师电脑，装 CK Pluely / CK Parrot；B=学生端，手机或另一台电脑），同时进入同一个腾讯会议或钉钉会议。

## Windows（A）
1. `winver` 确认版本（≥ 2004 / build 19041 为完整排除）。
2. 打开 CK Pluely → 设置 →「隐私自检」：各窗口应显示「已排除出录屏」（旧版显示「黑块」）。
3. 腾讯会议/钉钉中选择「共享屏幕 → 整个桌面」。A 上打开主窗口、控制台、截图框选层，提问让 AI 出答案。
4. 在 B 上观察：应完全看不到 Pluely 窗口（旧版 Windows 为黑块）。A 上自己能正常看到。
5. 按 Ctrl+Alt+Shift+H：A 上所有 Pluely 窗口消失；再按一次恢复。恢复后重复第 4 步，确认仍然看不到。
6. 设置 → 隐藏任务栏图标：确认任务栏与 Alt+Tab 中都没有 Pluely。
7. 用腾讯会议「本地录制」录一段，回放确认录像中也没有 Pluely。

## macOS（A）
1. 记下 macOS 版本。CK Pluely 设置 →「隐私自检」查看说明；CK Parrot 设置 → 通用 → 「共享屏幕时隐藏 Parrot 窗口」保持开启。
2. 先测「共享整个屏幕」，在 B 上观察窗口是否可见：macOS 14 及以下通常看不到；macOS 15+ 可能仍可见（系统限制）。
3. 再测「共享单个窗口」（如 PPT/浏览器）：B 上不应出现 Pluely/Parrot（任何版本都有效）。
4. 测一键隐藏 ⌘⌥⇧H，以及首次需要在「系统设置 → 隐私与安全性 → 屏幕录制」授权给腾讯会议/钉钉。
5. 记录：系统版本、会议软件版本、整屏/单窗口、B 端是否可见 —— 反馈给维护者。

## Linux
系统没有防录屏接口：请共享单个窗口，或使用一键隐藏快捷键。
